# Agent Research Prompt Post Design

## Purpose

Publish a `god-is-dead` post adapted from the supplied LinkedIn draft. It should sound personal and reflective while giving readers a concrete account of what the published research-manager prompt requires.

## Scope

- Create one Markdown post in `src/content/god-is-dead`.
- Use the collection's existing frontmatter fields and no new components, styles, images, or dependencies.
- Link to the published OpenAI prompt as the source.

## Structure

1. Open with the apparent result and why the prompt—not the mathematics—is the interesting part for ordinary AI practitioners.
2. Explain that this is not ordinary prompt formatting but an instruction to manage a research process.
3. Extract the operational lessons: diverse approaches, delayed convergence, tracking approach families, blocking theorem-strength gaps, delayed cross-pollination, adversarial review, concrete deliverables, and explicit completion criteria.
4. End with the argument that hard agentic prompting is process design: deciding how work explores, challenges itself, shares information, and stops.
5. Add a compact source link to the full prompt.

## Accuracy

- Attribute the proof claim to the published prompt/document rather than independently declaring the conjecture solved.
- State that the prompt allows up to 64 agents.
- Correct the supplied "one hour" claim: the prompt requires at least eight hours before returning or giving up.

## Voice

Use the site's direct, first-person, slightly skeptical style. Keep headings light and prose-led; use a short list only where it improves the extraction of practical lessons.

## Verification

Run the production build after adding the Markdown file.
