# Tetsubin Studio Images

## Goal

Help readers recognize the four Morioka studios by showing one representative tetsubin and one maker mark in each studio section.

## Design

Replace the existing diagram or generic workshop image in each studio section with a compact two-image gallery:

- Suzuki Morihisa: an official current tetsubin and a published `盛久` mark.
- Kunzan: an official current tetsubin and a sourced `薫山` mark.
- Iwachu: an official current tetsubin and an official `岩鋳`/`IWACHU` stamp.
- Kamasada: an owner-attributed current tetsubin and a sourced `釜定`/`KAMASADA` mark.

Reuse the blog's existing `.image-gallery` pattern. Add one shared `.two-up` figure rule so captioned pairs have equal columns and wrap on narrow screens. Store copies locally so the article does not depend on hotlinked images.

## Editorial Rules

- Credit and link the source in every caption.
- Say whether the source is the workshop, a publication, or a retailer.
- Treat a mark as a clue, not proof of authenticity or age.
- State that reuse permission is unconfirmed for copyrighted images published for editorial identification.
- Keep the article readable: no additional galleries, tables, or authentication checklist.

## Verification

Confirm every local image opens, every source link matches its caption, alt text identifies the useful visual detail, and the production build passes.
