<h2>Question</h2>

What can four common forms of storage evidence support, and where does each stop?

<h2>Materials</h2>

Use Flight 2's matched commercial pair and page; the [Yunnan Sourcing aged raw storage sampler page](https://yunnansourcing.com/products/aged-raw-pu-erh-tea-storage-comparison-sampler); city or climate labels already attached to selected Dayi examples; and the two Yee On warehouse descriptions used in Flight 12. The sampler and Yee On teas are documentation, not required lab purchases.

<h2>Procedure</h2>

Extract only explicit page statements. Classify each as observed page wording, vendor claim, inference, or unknown. Then build an evidence-strength table before reading tasting notes.

<h2>Record</h2>

| Evidence form | Strongest supported use | Unsupported inference |
|---|---|---|
| F2 matched commercial pair | A plausible storage-associated difference in the named set | Measured climate effect or complete custody |
| Multi-tea storage sampler page | How a seller groups several labelled storage categories | A controlled city comparison across different teas |
| City or climate label | The seller's stated location or broad condition | Actual continuous temperature, humidity, cleanliness, or airflow |
| Yee On warehouse description | The seller's stated process for each complete stored tea | One isolated cellar-duration, airing, or intensity effect |

<h2>What We Can Learn</h2>

When the teas are better matched and their handling records are clearer, we can be more specific about what storage may have changed. We should still write down what we do not know.

<h2>What This Cannot Tell Us</h2>

Taste cannot reconstruct every place a tea has been or turn one sample into a rule for a whole city. It also cannot give us an exact temperature and humidity history if no one measured it.

To learn more, we would need to split the same tea between known storage conditions, keep records, and taste the portions blind over time.

<h2>Cost and Reuse</h2>

No additional purchase. It reuses Flight 2 and Flight 12 pages and selected teas; the sampler is a reference page only.
